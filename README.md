# fabrica-electrica-simulador
Visualiza un circuito como una fábrica: el Voltaje es la presión que impulsa a los electrones, la Corriente es cuántos pasan por segundo, y la Resistencia frena su avance. Juntas definen la Potencia (ritmo de trabajo) y la Energía (consumo total acumulado). ¡Usa los deslizadores y explora el simulador!
